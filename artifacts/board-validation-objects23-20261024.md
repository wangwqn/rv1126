# RV1126 23 类候选模型板载验证（2026-10-24）

## 测试对象

- 板卡：ATK-DLRV1126，Linux 4.19.111，ARMv7。
- RKNN runtime：1.7.0；NPU driver：6.4.6.5.351518。
- 候选目录：`/root/rv1126_objects23_candidate`。
- 模型：23 类、320×320、INT8，三路输出均为 84 通道。
- 摄像头：IMX415，1080p 模式，TNR 2to1 开启。
- 主流：旋转后 1080×1920、H.264、4 Mbps、30 FPS。
- 子流：旋转后 360×640、H.264、600 kbps、30 FPS。
- 音频：8 kHz 单声道 G.711A/PCMA。

主机与板端的程序、RKNN、JSON 和标签图 SHA256 逐项一致。

## 单图推理

同一公开 COCO 验证图连续运行三次，输出完全一致：

| 次数 | 预处理 + 推理 + 后处理 |
| --- | ---: |
| 1 | 22.037 ms |
| 2 | 21.772 ms |
| 3 | 21.870 ms |
| 平均 | 21.893 ms |

检出人、椅子、笔记本电脑、显示器/电视和杯子；中文名称、置信度与框正常。
仍存在显示设备与笔记本电脑的重复/混淆框，因此这是部署通过，不代表精度验收通过。

## 实时管线

健康检查 3 秒窗口内主流增长 91 帧、子流增长 92 帧，RTSP 8554 正常，
`ErrCnt=0`、TNR ON、音频持续采集。

通过 ADB TCP 转发并发解码主、子流 30 秒：

| 流 | 帧数 | 平均帧率 | 解码/传输错误 |
| --- | ---: | ---: | ---: |
| main | 900 | 30.00 FPS | 0 |
| sub | 900 | 30.00 FPS | 0 |

主、子 Session 均探测到 H.264 视频及 8 kHz mono PCMA；主流 10 秒音频实际解码
得到 83680 个样本，平均 -39.0 dB、峰值 -19.4 dB。

运行统计超过 4950 帧时，主、子流均 `pts_gap=0`，AI `stale_drop=0`，
音频 `queue_drop=0`、`recoveries=0`，RTSP 队列高水位 2/8。
日志仅在相机刚启动、ISP 尚未完全出帧时出现一次 VENC0 取包超时；后续连续运行
未再次出现，因此不计为稳态丢帧。

## 结论和限制

23 类模型通过 RV1126 加载、单图推理、实时双流、音频和短时资源验证。
本次网络测试通过 USB ADB TCP 转发完成；没有 wlan0 地址，因此不代表 Wi-Fi UDP/TCP
验收。当前摄像头场景没有目标超过 0.25 阈值，仍须采集现场图片补训，并完成逐类实物、
30 分钟及 24 小时测试后，才能替换稳定 11 类模型。
