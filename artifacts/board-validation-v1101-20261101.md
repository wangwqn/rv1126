## v1.10.0 实测与问题

- Web `8080` 可通过 Wi-Fi 访问，`/api/health` 无需鉴权，受保护 API
  缺少 Bearer Token 时正确返回 HTTP 401。
- 状态、指标、配置、版本、Git 提交和 RTSP URL 读取正常。
- 30 秒 Wi-Fi RTSP/TCP 双流：主流900帧（30.00 FPS），子流899帧
  （29.97 FPS），无 H.264 解码或 RTP/RTSP 传输错误。
- 主、子流均包含 H.264 + 8 kHz 单声道 PCMA；10秒解码收到
  83,680个音频样本，峰值 -17.3 dB。
- `POST /api/config` 使用 `apply=true` 时返回 HTTP 400。原因是媒体
  图重启后约需15秒预热，v1.10.0只立即调用一次 `health`，因此将
  预热中误判为失败并回滚。回滚后媒体与配置正常。
